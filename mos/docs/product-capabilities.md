# MariOS 能力一览（客户可见）

本文汇总产品对外可陈述的能力模块，供介绍页、门户与售前材料对齐。不含内部研发清单。

## 商业运营

- 航次估算与 TCE（含 Worldscale、敏感度、方案对比、转租约）
- 租约 / 成交与审批、COA lifting
- 航次运营：靠港、午报、SOF、船期冲突提示
- 航次收尾清单（Closeout）：逐项核对 + 缺项自动生成跟进任务
- 装卸时间、滞期索赔、发票与收付款、GL 过账辅助
- 动态航次损益（估算 vs 实际）
- 主数据：船舶、港口、对手方（自定义类型 + 多联系人）

## 协同与智能

- AI 助手（任意页面 Ctrl+J）：自然语言取本租户数据，未配模型时回落规则引擎并标注
- MariAI 对话（`/ai/chat`）：多 Agent、只读工具调用、会话可管理
- AI Hub（`/settings/ai`）：服务商与模型配置、连通性测试、用量与配额、自带密钥不计入平台额度
- 邮件复核与抽取确认流程：多文件夹 / 时间窗同步、自动分类与字段抽取、生成业务草稿（估算 / 租约 / PDA / 发票）、忽略并记住发件人、归档到业务单据
- 航次计算 AI 填充：粘贴邮件或聊天记录 → 逐字段预览确认 → 填入估算表单（估算页 / 邮件详情 / 航次工作台三处入口）
- 例行任务中枢：待确认草稿（逐字段证据出处 + 四眼复核后写回）、例行任务（事件 / 时间窗触发，可增删改与手工运行）、技能模板
- 事件驱动的业务自动化：航次、租约、发票、PDA、燃油、索赔、NOR 等节点发出域事件，物化为任务、通知与 GL 过账尝试；异常留痕不阻断业务
- 单据模板与 PDF：14 类单据模板、带公司抬头、可定制 / 预览 / 导出 / 站内发送
- 模块化导航（租船、运营、财务、技术、分析与AI — 按角色分区，模块化）
- 全局搜索与角色工作台；每页「❓ 页面指引」操作指引
- 船队孪生与态势告警
- 角色数据看板

## 生态与开放

- 集成中枢连接器与完整 REST API
- DataOps：迁入向导与租户备份
