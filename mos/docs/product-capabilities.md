# VoyageOS 能力一览（客户可见）

本文汇总产品对外可陈述的能力模块，供介绍页、门户与售前材料对齐。不含内部研发清单。

## 商业运营

- 航次估算与 TCE（含 Worldscale、敏感度、方案对比、转租约）
- 租约 / 成交与审批、COA lifting
- 航次运营：靠港、午报、SOF、船期冲突提示
- 装卸时间、滞期索赔、发票与收付款、GL 过账辅助
- 动态航次损益（估算 vs 实际）
- 主数据：船舶、港口、对手方

## 协同与智能

- 邮件复核与抽取确认流程
- AI Hub（多技能 / 提供商配置）
- 全局搜索与角色工作台
- 船队孪生与态势告警
- 角色实时大屏

## 生态与开放

- Microsoft 365：邮件、Teams、SharePoint / OneDrive、插件与 Webhook
- 集成中枢连接器与完整 REST API
- DataOps：迁入向导与租户备份

## 平台与治理

- 多租户 SaaS、许可证与用量
- 用户 / 角色 / SSO / 语言术语
- 平台运维：数据源、初始化、部署档案、监控预警
- 知识中心：检索与问答（登录后 `/help`）
- 多语言产品界面

## 船舶技术（可选模块）

- 证书、PMS 工单、缺陷、船员快照
- 外部 PMS 连接（含主流厂商对接入口）
