# MariOS 用户指南

面向业务用户与租户管理员的操作说明。更细的条目可在产品内 **知识中心**（`/help`）检索或问答。完整图文步骤见 **全流程操作手册**：开发环境打开 [`/manual/`](/manual/)（文件 `apps/web/public/manual/index.html`）。

## 1. 产品是什么

MariOS 是航运商业操作系统：把估算 → 租约 → 航次执行 → 装卸时间 / 索赔 → 燃油 → 财务结算收进同一工作台，并与 Microsoft 365、开放 API、多语言术语库协同。

## 2. 登录与角色

侧边导航按业务模块分区（工作台、租船、运营、财务、技术、分析、主数据、管理、平台），每个角色只看到自己相关的模块与页面。

| 角色示例 | 主要模块 | 典型入口 |
|----------|----------|----------|
| 租船 | Chartering / Analytics | 工作台 · 估算 · 租约 · 邮件复核 · 交易风险 |
| 运营 | Operations / Technical | 航次 · MariLink · 燃油 · 排放 · 船队孪生 |
| 财务 / 滞期 | Finance / Analytics | 财务台 · 联营池 · 交易风险 · 分析数据看板 |
| 机务 | Technical / Operations | 船舶管理 · 船队孪生 · 燃油 · 航次 |
| 管理层 | Analytics / 全模块 | 数据看板 · TCE 看板 · 情景推演 · 损益 |
| 租户管理员 | 全模块 + Administration | 用户 · 安全 · Office 生态 · 集成 · 语言术语 |
| 平台运营 | Platform | `/platform` · 租户 · 数据面与部署 · 品牌 · 健康 |

演示租户码 `demo`；平台运营租户码 `sys`。

全局搜索：**Ctrl+K**。帮助：**顶栏 / 侧栏 → 知识中心**。

## 3. 商务主链路

1. **估算**：录入船、货、航程与 Worldscale 等参数 → 计算 TCE → 敏感度 / 对比 → 转租约。  
   （已有邮件 / 聊天记录时，可用「从文本填充」粘贴解析，逐字段核对后写入表单。）
2. **租约**：审批（若启用）→ 激活。  
   （租约修订获批会发出域事件，自动通知相关部门并派财务复核任务。）
3. **航次**：靠港时间线（本地时区）→ 午报 / SOF。  
   （航次工作台 → **Closeout** 收尾清单逐项核对：ATA/ATD、SOF 事实、装卸时间定稿、索赔了结、发票签发、加油交付、TCE 对比。）
4. **装卸时间与索赔**：条款 + SOF → 计算定稿 → 索赔 / 开票。  
5. **分析**：航次损益（估算 vs 实际 vs 差异）。

## 4. AI 与自动化（贯穿主链路）

AI 与自动化不是独立旁路：AI 负责「读懂与起草」，流程负责「物化待办」，**落库一律人工确认**。

| 能力 | 入口 | 做什么 |
|------|------|--------|
| **AI 助手** | 任意页面 `Ctrl+J` | 用自然语言问本租户数据（TCE、逾期发票等）；未配模型时回落规则引擎并标 `rules` |
| **MariAI 对话** | `/ai/chat` | 选 Agent 新建会话，Agent 可调只读工具查询；会话可重命名 / 归档 / 删除 |
| **AI Hub** | `/settings/ai` | 配置模型服务商与模型、连通性测试、默认参数；查看用量与配额；自带密钥（BYO key）不计入平台额度 |
| **邮件复核与 AI 落地** | `/email/review` | 同步邮件（天数 / 条数 / 文件夹可控）→ 自动分类与字段抽取 → 生成估算 / 租约 / PDA / 发票草稿、忽略并记住发件人、归档到业务单据 |
| **航次计算 AI 填充** | 估算页 / 邮件详情 / 航次工作台 | 粘贴邮件或聊天记录 → 逐字段预览（值 + 来源 + 置信度）→ 勾选应用 |
| **例行任务中枢** | `/routine` | 三个 Tab：待确认草稿 / 例行任务 / 技能模板；草稿逐字段带证据出处，四眼规则（第二人复核）后才写回 |
| **域事件自动化** | 航次、租约、发票、PDA、燃油、索赔、NOR 等节点 | 事件物化为跟进任务 + 站内通知 + GL 过账尝试；异常只留痕、不回滚业务 |
| **航次收尾清单** | 航次工作台 → Closeout | 逐项 ok / 缺项 + 缺项任务（角色 + 时限） |
| **文档与 PDF** | `/settings/templates` | 14 类单据模板（发票、装卸时间计算书、SOF、对账单……）带公司抬头，可定制、预览、导出 PDF 与站内发送 |

规则边界：AI 只起草不写台账；事件只产生待办，不推进状态机、不代替审批；任务可由人手工改 / 删 / 提前触发。

## 5. 其他业务模块

除了第 3 节的主链路与第 4 节的 AI 自动化，下面这些模块同样在侧边导航里按角色开放：

| 模块 | 入口 | 做什么 |
|------|------|--------|
| **调度与货物台账** | 运营 · 调度管理 · 货物台账 | 船舶/港口 Gantt 排期、冲突检测、租家机会、货物（Parcels）与期权 |
| **燃油与排放** | 运营 · 燃油台 · 排放 / FuelEU | 加油需求与 ROB 存量、硫合规、CII / FuelEU 合规仪表盘 |
| **船舶管理** | 技术 · 船舶管理 | 船舶台账、保养、证书、坞修、代理与机务文档 |
| **报表与分析** | 分析 · 报表 · 报表设计器 · 定时报表 | 系统报表、可视化数据地图（Report Designer）、定时分发 |
| **船队孪生（Twin）** | 技术 · 船队孪生 | 船舶状态画像、航次 L4 预测与告警 |
| **交易与风险** | 分析 · 交易风险 | FFA / 纸货头寸、盯市（MtM）、敞口与限额 |
| **联营池（Pooling）** | 财务 · 联营池 | 多船共享航次、收益分摊与分账 |
| **知识中心** | `/help` | 文章检索 + 问答（新增 AI 与自动化栏目） |
| **平台与治理** | `/platform` · 租户 · 数据面与部署 · 品牌 · 健康 | 租户开通、模块许可与计费、数据面部署、品牌与健康（平台运营角色） |

每个页面右上角的 **「❓ 页面指引」** 按钮打开该页的操作指引（用途 / 标准流程 / 上下游 / 角色 / 延伸阅读），与知识中心互相链接。

## 6. Microsoft 365

控制平面 → **Office 生态**：连接组织、同步邮件 / 文件 / Teams、出站 Webhook、侧载 Outlook / Teams / Excel 插件。邮件同步后的复核与 AI 落地见第 4 节。详见 [office-ecosystem.md](./office-ecosystem.md)。

## 7. 集成与 API

- OpenAPI：API 主机 `/docs`（生产环境 `ENV=production` 时关闭 `/docs` 与 `/openapi.json`）  
- API 密钥：控制平面 → API 密钥（`X-API-Key`）  
- 连接器：控制平面 → 集成中枢  
- 说明：[api-integrations] 知识中心文章

## 8. 数据与部署（平台运营）

默认本地开发 SQLite；Compose / 生产推荐 PostgreSQL（库名 `voyageos`）。共享主库 + 租户隔离；可按租户登记独立数据源（切库路由预留）。

- 数据面与部署：[platform-data-deploy.md](./platform-data-deploy.md)
- 部署指南（Compose / 发布 / 反代 / 备份 / 安全清单）：[deployment.md](./deployment.md)

## 9. 多语言

顶栏切换语言；管理员可维护航运术语。默认界面语言为 English，完整支持简体中文等。
