为什么需要 MariOS / Why

告别 Excel + 邮件的航次管理

滞期费 Demurrage 算错一位小数，就是数万美元的争议。数据散落在表格与收件箱里，每一次结算都在重复对账。

传统方式 · Legacy

Excel + 邮件 + 经验

  • 估算靠手工：TCE 公式各自维护，佣金、EU ETS 碳成本漏算难追溯
  • Laytime 靠翻 SOF：SHINC/SHEX、节假日、港口时区逐条人工扣算，一算几天
  • Timebar 靠日历提醒：索赔时效错过即灭失，无人兜底
  • P&L 月底才见：actual 与 accrual 口径混乱，航次盈亏事后才知道
  • 数据权属不清：多租户混跑、会话裸奔、操作无审计
→
MariOS 方式

一个系统，全链路闭环

  • TCE 引擎：Decimal 精度、金样例背书，双佣金与 EU ETS 碳成本内建
  • Laytime 引擎：全条款覆盖，一键从 SOF 生成计算书，两港可逆/合并互抵
  • Timebar 自动推算：届满前 14 天主动预警，部分和解全程留痕
  • 双口径 P&L：actual / accrual 全行项实时可见，一键转发票、红冲可逆
  • 企业级底座：多租户隔离 61 个攻击向量测试门禁，全量审计日志
全链路闭环 / Closed Loop

一次录入，全程流转

估算结果直接转租约，租约条款驱动执行校验，SOF 一键生成滞期计算书，索赔定稿一键转发票——数据不落地、不重复录入。

业务主链路：上游数据自动带入下游 实绩回流：actual 数据校准估算模型 全程状态机驱动，操作留痕可审计
产品能力 / Capabilities

十大模块，覆盖航运商业全场景

模块化单体架构：按需启用、统一数据模型，每一项能力均已落地实现并通过自动化测试验证。

航次估算

Voyage Estimation
  • TCE 引擎：Decimal 精度，金样例数值背书
  • address commission / brokerage 双佣金
  • EU ETS 碳成本直接进入估算
  • 多牌号油价（VLSFO / MGO）、多腿航线按距离/航速推天数
  • 货量 tolerance 与积载校验、敏感度分析（乘法/加减扰动）

租约管理

Fixture & Charter Party
  • VC / TC / COA 全租约形态
  • 18 个条款字段化：demurrage/despatch rate、SHINC/SHEX、GENCON/NYPE、laycan
  • 期租 hire 周期发票与 off-hire 扣减
  • 租约变更单审批流
  • 制裁筛查激活阻断，合规前置

航次执行

Voyage Execution
  • SOF 标准 12 事件码（NOR/EOSP/POB/COMMENCED…）与时序校验
  • B/L date 字段化，单证要素结构化
  • 午报：ROB / 天气 / ETA 偏差预警
  • off-hire 事件全程记录
  • 数字孪生船队视图，船况一屏尽览

滞期 / 索赔

Demurrage & Claims
  • Laytime 引擎全条款：SHINC/SHEX/EIU、节假日、港口时区
  • 一键从 SOF 生成计算书，可逆/合并两港互抵
  • 定稿锁定与导出，计算过程可复现
  • Timebar 自动推算 + 14 天预警
  • 部分和解、一键转发票

财务结算

Finance & Settlement
  • 发票全状态机 + 审批 + GL 总账
  • 红冲 credit note、付款冲正，全程可逆
  • 多币种折算，汇率留痕
  • P&L 全行项 actual / accrual 双口径
  • 应收应付 aging 账龄分析

燃油管理

Bunker Management
  • 询比价全流程，指数定价（如 SIN380+12）
  • BDN 偏差告警，交付量异常即时可见
  • ROB 守恒校验，油账笔笔平衡
  • 燃油成本按航次自动分摊

排放合规

Emissions & Compliance
  • 真 CII 评级：IMO MEPC 评级带，非估算值
  • EEOI 能效指标自动计算
  • EU ETS 自动航线分摊，碳成本归属清晰
  • FuelEU 罚没测算，合规成本提前量化

船舶管理

Ship Management
  • 证书扫描件上传（PDF/图片），版本管理：自动升版、历史可回看可恢复
  • 全船队证书总览，到期前 30 天自动提醒责任人
  • PMS 工单–备件消耗联动，库存自动核减
  • 船员 STCW 证书预警
  • Drydock 自动占船期，排期不冲突

企业级安全

Enterprise Security
  • 多租户隔离：61 个攻击向量测试门禁
  • HttpOnly Cookie 会话，抵御 XSS 窃取
  • 全量审计日志，操作可追溯

质量工程

Quality Engineering

Workspaces & Collaboration

工程加固 / Hardening

P0–P3 加固完成：生产级，不是演示级

安全、质量、可观测性三位一体。每一项声明都有测试与机制背书，可验证、可审计。

多租户隔离 Multi-tenancy

61 个攻击向量纳入测试门禁：跨租户读写、IDOR、会话劫持等场景逐一举证拦截。数据边界由测试而非承诺保证。

审计与可观测 Auditability

关键操作全量审计日志；X-Request-ID 贯穿请求全链路，一次滞期计算从 API 到数据库的每一步都可回放定位。

部署与集成 / Deploy & Integrate

单机可跑，云上可扩

模块化单体架构：一条命令在本机拉起完整环境，业务增长后平滑扩展至多云。

marios — deploy
# 克隆后一条命令启动完整栈
$ docker compose up -d

# 数据库迁移（Alembic，108 表基线）
$ docker compose exec api alembic upgrade head
INFO  [alembic] Running upgrade -> base, 108 tables

# 部署后自检：环境、迁移、核心链路
$ docker compose exec api python -m app.selfcheck
✓ database  ✓ migrations  ✓ auth  ✓ tenant isolation
✓ tce golden samples  ✓ laytime engine
SelfCheck passed — MariOS is ready.

Docker Compose 单机部署

模块化单体打包为标准容器编排，不依赖云厂商。内网、私有云、客户机房均可落地；架构预留多云扩展路径。

开放 API + Webhook

全量业务能力经 REST API 开放；业务事件（定稿、审批、预警）经 Webhook 实时推送，轻松接入既有系统与数据管道。

Microsoft 365 生态

原生融入 Teams / SharePoint / Outlook：审批进 Teams、单证归档 SharePoint、预警走 Outlook，船员与岸基零培训上手。
